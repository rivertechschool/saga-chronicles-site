# Saga Chronicles

Landing page for sagachronicles.com.

Static HTML/CSS — no build, no framework. Push to `main` to deploy via GitHub Pages.

## Files

- `index.html` — landing page
- `style.css` — styles (cache-bust via `?v=N` in index.html when changed)
- `assets/hero_dawn_council.jpg` — hero painting
- `CNAME` — custom domain for GitHub Pages (do not delete)
